在任何 Agent 里都能用

提示词不绑定任何一家的模型或工具。它把风格写成可执行的规范：配色、字体、材质、动效、分镜、技术路线和自检清单，再按你的 Agent 能力调整交付方式。

第一步

挑风格，写主题

在卡片上点“配置提示词”。主题可以是一句话，也可以贴一段脚本；不写就让 Agent 先帮你拆节拍。

第二步

选 Agent 类型和格式

能运行命令的助手会直接渲染成 MP4；只能写网页的会交付可拖动的播放器；纯聊天模型会给你一个单文件网页。还能导出 AGENTS.md、Cursor 规则、SKILL.md 或 DESIGN.md。

第三步

先看分镜，再开工

默认要求 Agent 先交分镜表等你确认。需要更像原样时勾选“附带参考源码”，把本站这一风格的绘制代码一起交给它。
