# 百象动效图鉴

**打开网站：https://zcccccc22.github.io/ai-style-atlas-cn/**

同一个 15 秒故事“AI 是怎么学习的？”，拍成 67 支风格完全不同的短片。可以按分类筛选、拖动时间轴对比，还能为任意 AI 编程助手生成中文提示词。

## 点个 Star 收藏

图鉴会一直更新，新风格会不断加进来。觉得有用就点右上角的 ⭐ Star，以后随时能找回来。

## 想要什么风格？

[告诉我你想要的风格](https://github.com/zcccccc22/ai-style-atlas-cn/issues/new?template=style-request.yml)，我做出来更新到网站上。

## 说明

所有预览都是代码绘制的原创画面，没有使用其他网站的视频和提示词。提示词的工作流程、评审标准和 15 种风格的标志特征改编自开源项目 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)（MIT）。
